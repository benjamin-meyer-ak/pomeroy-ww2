2  Setup and Reproducing the Work

This chapter says what is needed to rebuild the transcription from the scanned PDFs, and shows the file that runs every step in order. Every script the project uses is shown in full in the chapter for its step. The only things not generated by code are the three scans, the settings file data/volume_config.csv (described below) and the human corrections in data/corrections.csv.

2.1 Rebuilding from scratch

With the three PDFs saved as data/raw_pdf/vol1.pdf, vol2.pdf and vol3.pdf:

  1. Open the RStudio project (or set the working directory to the project root).
  2. Restore the package versions recorded in renv.lock: renv::restore(lockfile = "renv.lock").
  3. Run the whole pipeline: targets::tar_make().
  4. Render the book: quarto render.

Step 3 is the single entry point. It profiles every page, downloads any missing Tesseract language data, crops and OCRs all 378 pages, builds the triage tables, runs the settings experiments and applies the corrections. It takes roughly 30 minutes on a six-core machine (about 4 minutes for the inventory, 20 for OCR, the rest for tiering and experiments). Steps whose inputs have not changed are skipped on a rerun, and OCR results are cached page by page, so an interrupted run resumes where it stopped.

Show code 
# The whole pipeline, from the scanned PDFs to the final tables. Run with
#   targets::tar_make()
# Steps whose inputs have not changed are skipped; OCR results are also cached
# page by page in data/interim/ocr/, so an interrupted run resumes.
library(targets)
tar_source("R")
tar_option_set(packages = c("tidyverse", "pdftools", "magick", "tesseract"))

list(
  # Inputs: per-volume settings and the scans
  tar_target(config_file, "data/volume_config.csv", format = "file"),
  tar_target(config, read_csv(config_file, show_col_types = FALSE)),
  tar_target(pdf_files, file.path("data/raw_pdf", config$file), format = "file"),

  # Step 1: profile every page (blank, duplicate and layout checks)
  tar_target(inventory_file, run_inventory(config, pdf_files), format = "file"),

  # Step 2: crop, render and OCR every page
  tar_target(languages, ensure_languages(config)),
  tar_target(ocr_files, run_ocr(config, pdf_files, languages), format = "file"),

  # Step 3: tiers, draft text, review images, manual queue
  tar_target(output_files, build_outputs(config, ocr_files), format = "file"),

  # Step 4: settings experiments reported in the book
  tar_target(experiment_files, run_experiments(ocr_files), format = "file"),

  # Step 5: final text = OCR draft with the human corrections applied
  tar_target(corrections_file, "data/corrections.csv", format = "file"),
  tar_target(final, {
    output_files
    apply_corrections(corr_path = corrections_file)
  })
)
Show code 
flowchart TD
  config[volume_config.csv] --> inv[Inventory]
  pdf[Scanned PDFs] --> inv
  config --> lang[Install languages]
  lang --> ocr[Crop and OCR every page]
  pdf --> ocr
  ocr --> out[Tiers, drafts, review images]
  ocr --> exp[Settings experiments]
  out --> final[Final text]
  corr[corrections.csv] --> final

Two checks were made that a rerun gives the same answer. Re-running the inventory from scratch reproduced the earlier ink measurements exactly. Re-cropping and re-OCRing three pages from three different files gave identical text, word boxes and confidences (apart from floating-point noise of about 1e-14).

2.2 System requirements

The R packages bundle their own copies of the native libraries, so no separate installs are needed on Windows:

Component Provided by
PDF rendering (poppler) pdftools
Image processing (ImageMagick) magick
OCR engine (Tesseract) and the English model tesseract
Other language models (deu, fra) downloaded by the pipeline with tesseract_download()

The language models are the one thing fetched from the internet during a run. Tesseract’s results can differ slightly between engine and model versions, so the versions below are part of the record.

2.3 Package versions

Exact versions are pinned in renv.lock. The ones that matter most for the output:

Show code 
tribble(
  ~package, ~used_for,
  "pdftools", "Render PDF pages to images and read page sizes",
  "magick", "Crop, convert and annotate page images",
  "tesseract", "Local OCR with word-level confidence",
  "spelling", "Dictionary check used to flag unfamiliar words",
  "targets", "Runs the pipeline and skips finished steps",
  "tidyverse", "Data handling and plots",
  "shiny", "Proofreading app",
  "bslib", "Proofreading app layout",
  "ellmer", "Vision-model calls (planned, not yet used)"
) |>
  mutate(version = map_chr(package, \(p) as.character(packageVersion(p)))) |>
  kable()

Tesseract engine version 5.3.2. Languages installed on the machine that built this book: eng, osd. The 1966 journal is configured for eng+deu+fra, so the pipeline downloads deu and fra the first time it runs on a machine that lacks them, and re-OCRs volume 2 if it was previously processed with fewer languages.

2.4 The settings file

Everything that differs between volumes lives in one table, data/volume_config.csv. The pipeline reads it; nothing about a particular volume is written into the scripts.

Show code 
read_csv("data/volume_config.csv", show_col_types = FALSE) |>
  select(-notes) |>
  kable()

The file is written by hand, from the inventory (see Page Extraction) and from looking at the scans. It is the record of those judgments:

Column Meaning and source
layout, text_side spread or page; which half of a spread holds the text. From the inventory’s page shapes and ink on each half.
portrait_pages Pages in a spread file that are single pages and are not cropped. From the inventory’s orientation column.
front_matter_pages, first_entry_page Read from the scans (vol2 only so far).
check_pages Pages worth a second look because the inventory flagged them. Informational.
force_manual_pages Pages sent straight to tier A because OCR is known to fail on their layout.
duplicate_pairs Pages that look repeated, from the inventory’s duplicate check. Informational: none is dropped.
ocr_langs Tesseract languages, joined with +.

2.5 Keys

Vision-model transcription is planned but not used so far. When it is added, API keys will be read from environment variables set in .Renviron, which is excluded from version control.

2.6 Project layout

Scans and page images stay on the local machine. Everything else is committed, including the cached OCR, so the book can be rebuilt without redoing the 20-minute OCR step.

Path Contents In git
data/raw_pdf/ The three scanned PDFs No
data/pages/ 300 DPI page PNGs and review images No
data/interim/ Page inventory, cached OCR results, experiment results Yes
data/volume_config.csv Per-volume settings Yes
data/corrections.csv Human fixes from the proofreading app Yes

R/ Pipeline code Yes

_targets/ The targets cache No
